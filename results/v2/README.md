# v2 outputs (second calibration)

Outputs of model version 2, produced by `R/v2/*.R` (`Rscript R/v2/run_all.R`;
calibrations cached in `models/v2/`). v2 added a Scotian-Shelf-constrained
plankton resource, explicit early-life background mortality, low reproduction
levels and a hindcast-calibrated forage boom, but kept the forage -> cod
interaction at 1 (purely size-based). It is kept unchanged for reference; the
main model is v3. `SUMMARY.md` here is the v2 summary (covering v1 and v2).
