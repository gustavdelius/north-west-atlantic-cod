# v1 outputs (naive calibration)

Outputs of the first model version, produced by `R/v1/*.R` (run with
`Rscript R/v1/run_all.R`). v1 is kept unchanged for reference; the main model
is v2 (`R/*.R`, `results/`, `figures/`, `models/`). See `results/SUMMARY.md`
for why v1 could not test the hypothesis. `SUMMARY.md` in this folder is the
original v1 summary.
